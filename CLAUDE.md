Отвечай мне по-русски, код и комментарии в нём пиши по-английски. Не копируй ничего из MobaXterm (код, иконки, тексты), только повторяем нужную функциональность своей реализацией.

## Цель
Быстрое, красивое, нативное приложение в стиле Apple (HIG): SwiftUI + AppKit где нужно, тёмная и светлая тема, нормальные hotkeys, вкладки, сайдбар. Главная ценность: SSH-сессии без лимита на количество, терминал в центре, файловый браузер сбоку, X11.

## Имена и идентификаторы
- Название приложения: AbobaXTerm
- Bundle ID: com.mikhail.AbobaXTerm
- Данные приложения: ~/Library/Application Support/AbobaXTerm/
- Проект лежит в ~/AbobaXTerm (там уже сделан git init).

- Проверь наличие Xcode, Command Line Tools и Homebrew. Если чего-то нет, скажи мне, что поставить.

## Требования (по приоритету)
1. Менеджер SSH-сессий
   - Неограниченное число сохранённых сессий, папки/группы, поиск, избранное.
   - Поля: имя, host, port, user, ключ/агент/пароль, jump host (ProxyJump), доп. опции, цвет/иконка.
   - Хранение: JSON в ~/Library/Application Support/AbobaXTerm/. Пароли только в Keychain, не в файлах.
   - Подхватывать ключи и агент из ~/.ssh. Позже: импорт из ~/.ssh/config и из экспорта сессий MobaXterm.
2. Терминал на главном экране
   - Вкладки, на каждую сессию своя вкладка. Эмулятор: SwiftTerm.
   - Подключение через системный ssh в PTY (чтобы работали мои ~/.ssh/config, агент, ProxyJump). Для переиспользования соединения используй ControlMaster/ControlPath, чтобы терминал и файловая панель шли по одному подключению.
   - Пароли подставлять через SSH_ASKPASS-хелпер с Keychain, а не вводом в PTY.
3. Файловый браузер слева внутри сессии (SFTP)
   - Дерево папок удалённой ФС, навигация, путь сверху, обновление.
   - Создать/переименовать/удалить файл и папку (с подтверждением удаления).
   - Drag-and-drop в обе стороны (Finder <-> панель), прогресс и отмена передач в фоне.
   - Двойной клик по файлу открывает его во встроенном редакторе: подсветка синтаксиса, сохранение сразу заливает файл обратно, предупреждение если файл изменился на сервере.
   - Для SFTP сначала сделай короткий спайк и выбери между Citadel (SwiftNIO SSH), libssh2 и sftp подпроцессом. Объясни выбор в 3-4 строках, потом реализуй.
4. X11
   - Галочка «X11 forwarding» в настройках сессии (ssh -Y).
   - Приложение само находит XQuartz (/opt/X11), при необходимости запускает его и выставляет DISPLAY. Если не установлен, показать понятную подсказку (brew install --cask xquartz).
   - Главный сценарий для проверки: с безголового Linux-сервера запускаю virt-manager, и оно открывается отдельным окном на маке. Проверь на xeyes/xclock и опиши, что нужно проверить мне на реальном сервере.
5. Потом (не в первой итерации): туннели/port forwarding с GUI, сниппеты/макросы, multi-exec в нескольких вкладках, иконка приложения (придумай свою оригинальную).
6. Потом: мониторинг сервера внизу открытой SSH-вкладки (строка состояния): CPU usage + мини-график, оперативка (всего / занято), загрузка сети (in/out), uptime, пользователь, занятость диска. Данные брать по тому же ControlMaster-подключению, без установки агентов на сервер.
